# 普润制衣团购仓平台

项目已经拆成三个独立部分：

- `miniapp/`：微信小程序用户端
- `server/`：商品 API、SQLite 数据库和图片存储
- `server/public/admin/`：商品管理后台

## 现在如何查看效果

### 1. 打开商品管理后台

双击根目录的 `启动管理后台.cmd`，浏览器会自动打开：

`http://127.0.0.1:3000/admin/`

本地演示密码：`admin123`

可以进行：

- 新增、编辑和删除商品
- 修改款号、名称、分类、价格、颜色、尺码等信息
- 按 S、M、L、XL 等尺码修改库存，总库存自动汇总，并查看尺码库存预警
- 下载 Excel 库存模板，按款号和尺码批量导入库存；错误行会整份回滚并提示具体原因
- 上传多张 JPG、PNG 或 WebP 图片
- 保存为草稿，或控制商品上架/下架
- 搜索商品并按发布状态筛选

### 2. 在微信开发者工具查看小程序

项目已经导入微信开发者工具，工具版本为 Stable v2.01.2510290。

1. 先启动管理后台。
2. 打开微信开发者工具中的 `App` 项目。
3. 点击顶部“编译”，或在模拟器中刷新页面。
4. 首页、分类页和商品详情页会读取后台中“已上架”的商品。
5. 管理后台保存商品、分类、轮播图、图片或库存后，小程序重新进入相应页面即可读取最新数据，不需要重新编译或重新审核。

如果需要停止本地服务，双击 `停止本地服务.cmd`。

## 已实现功能

小程序端：

- 首页品牌横幅和动态商品分类
- 文字搜索与拍图识别商品、分类、价格排序和商品列表
- 商品画册、价格、颜色和尺码
- 无需登录即可浏览、搜索、查看库存和使用设计功能
- 首页和分类页展示总库存，详情页展示每个尺码的实时库存、低库存及缺货状态
- 商品页提供独立详情页和实拍图页，可查看详情文案、详情长图及分类实拍图
- 在线服装设计演示
- 个人中心
- 后端短暂不可用时优先使用最近一次成功加载的服务器缓存，不展示过期演示商品
- 首页、分类和商品详情采用版本化缓存、固定骨架和稳定图片占位；列表使用缩略图，点进商品后再加载清晰图
- 图片切换采用双缓冲，新图加载完成前保留旧图，避免轮播、颜色切图和页面首屏出现白闪

管理端与后端：

- 管理员密码登录与会话保护
- 所有已登录后台账号均可覆盖导入库存；只有主管理员可管理后台账号
- 登录失败限速：同一来源连续输错 5 次后暂时锁定 15 分钟
- 商品新增、查询、编辑、上下架和删除
- 团购价作为默认价，并可按商品尺码顺序设置多个不重叠的特殊尺码区间价
- 库存编辑、低库存统计与 SQLite 持久化
- 图片上传与本地存储
- 保存商品、分类或店铺设置后，自动删除已不再被任何内容引用的旧上传图片；共享图片不会误删
- 粘贴外部 HTTPS 图片链接时先下载到本服务器，数据库仅保存 `/uploads/...` 本地路径，不依赖原图片站点
- 商品主图、详情长图和带分类的实拍图分别管理
- SQLite 持久化数据库
- 小程序公开商品接口
- 拍图识别先使用本地图片索引召回候选，再由可选的 Gemini 兼容接口进行多图复核；接口超时、繁忙或额度不足时自动降级为本地结果
- 自动化接口测试
- 每日生成 SQLite 一致性备份并清理超过 5 天的旧备份；同时清理超过 24 小时仍未被使用的上传图片

库存名称对应关系会长期保存在 SQLite 中。同一个“来源名称 + 内部编码”可人工对应一至两个小程序商品，并为每个商品分别选择颜色。首次处理完“库存对应”页面的待对应项并保存后，后续每日上传含相同来源名称和内部编码的 Excel 会自动复用人工对应，同时更新这两个商品；新出现的名称会再次进入待对应列表。

## 本地与正式上线的区别

本地开发使用 `http://127.0.0.1:3000`。它只适用于电脑上的微信开发者工具，手机预览不能访问电脑自身的 `127.0.0.1`。

正式环境当前使用 `https://cpminiapp.xinghaiapp.top`：SQLite 数据库与全部商品图片均保存在自有服务器，微信公众平台请求域名也使用该域名。上线维护时需要继续执行强管理密码、固定会话密钥和定期备份。

智能图片复核只在后端启用，密钥不能写入小程序或提交到 Git。配置项见 `deploy/cpminiapp.env.example`。推荐使用 `gemini-3.7-flash`、8 个候选、18 秒超时；未设置 `IMAGE_RERANK_BASE_URL` 或 `IMAGE_RERANK_API_KEY` 时自动使用原有本地识别。

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 自动验证

安装 Node.js 22.5 或更高版本后运行：

```powershell
pnpm test
```

测试覆盖管理登录、商品新增、图片上传、编辑、上架、公开查询和删除。

生产服务器启用 `deploy/cpminiapp-maintenance.timer` 后，每天会执行：

```bash
node scripts/daily-maintenance.mjs
```

默认每天保留最近 5 天数据库备份，并给未保存完成的新上传图片保留 24 小时缓冲期。

首次部署高清图片预览，或批量导入历史商品图片后，执行以下命令预生成 2000px 高质量 WebP 预览图，避免用户首次点击时等待服务器临时处理：

```bash
npm run build:image-thumbnails
```

该任务默认并发处理 2 张图片；服务器资源较充足时可使用 `node scripts/build-image-thumbnails.mjs --concurrency=4`。
